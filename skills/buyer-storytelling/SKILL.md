# Storytelling acheteurs européens

## Persona acheteur

Cible primaire : **femmes 28-55 ans, Europe de l'Ouest** (FR, DE, NL, BE, IT principalement), revenus moyens à supérieurs, sensibles à :

- L'authenticité (pas de production de masse)
- La traçabilité (qui fait quoi, où, comment)
- L'éthique (commerce équitable, conditions de travail)
- L'esthétique (déco maison, pièces uniques)

Cible secondaire : **acheteurs B2B européens** — boutiques de déco, hôtels, restaurants, concept stores qui veulent du stock unique avec une histoire.

## Tonalité

- **Précis, pas lyrique.** Pas de "voyage des sens", pas de "trésor caché". Faits + détail sensoriel concret.
- **Première personne pour l'artisan, troisième pour la plateforme.** "Khaled travaille l'argile depuis 22 ans" puis "Médina Digital vérifie chaque atelier".
- **Anglais britannique** par défaut. Français pour le marché FR. Allemand quand la traduction est validée.
- **Pas de mots fourre-tout** : éviter "ethnic", "exotic", "oriental", "tribal", "boho". Utiliser le nom de la région tunisienne.

## Structures qui marchent

### Story d'artisan (page profil + carrousel social)

1. Hook visuel : photo des mains au travail, pas du visage en pose
2. Une phrase d'accroche : "Khaled façonne 30 plats par semaine. Chacun prend deux jours."
3. Contexte : où, depuis quand, héritage familial éventuel
4. Détail technique : la matière, la technique, ce qui rend ce travail spécifique
5. Ce qu'on peut acheter chez lui aujourd'hui (lien produits)

### Page produit narrative

- Titre direct (pas de jeu de mots)
- 3 photos minimum : produit, détail, contexte d'usage
- Description : usage, dimensions, matériaux (faits)
- Story courte de l'artisan (encart distinct)
- Empreinte / DPP (encart distinct, lien vers la page TrustTag)
- Avis (quand disponibles)
- Cross-sell : "Du même atelier" + "Style similaire"

### Post Instagram / TikTok

- Format vidéo 15-30s : un geste artisanal en gros plan, son ambiant
- Légende : 1 ligne d'accroche + 1 ligne de contexte + lien bio
- 5-7 hashtags max, ciblés (#handmadeNorthAfrica, #Tunisianceramics, #slowdesign), pas de spam de 30 hashtags

### Post Pinterest

- Image verticale 1000×1500
- Texte overlay minimal (1-3 mots)
- Description avec mots-clés SEO recherchés ("handmade ceramic plate Tunisia")
- Pin lié directement à la page produit

## SEO

Mots-clés primaires à cibler par cluster :

- **Céramique** : handmade ceramic, Tunisian pottery, Nabeul ceramics, hand-painted plates, North African pottery
- **Textile** : Tunisian rug, handwoven textile North Africa, fair trade kilim, Berber weaving
- **Cuir** : Tunisian leather, handcrafted leather goods Tunisia, North African leather
- **Bijoux** : Berber jewelry, silver Tunisian jewelry, handmade ethical jewelry

Pour chaque page produit/catégorie : titre SEO < 60 car, méta description < 155 car, H1 unique, alt text photos.

## Cohérence avec le pitch

Le projet mise sur "le pont manquant entre artisans tunisiens et acheteurs européens". Le storytelling doit incarner ce pont :

- Côté artisan : pas folklorisé, pas musée. Vivant, contemporain, économiquement actif.
- Côté acheteur : pas mission humanitaire. Achat de qualité avec valeur ajoutée éthique.

## Anti-patterns

- ❌ "Plongez dans l'âme de la Tunisie" — vide, condescendant
- ❌ Photos de souks colorés génériques pour vendre un objet précis
- ❌ Promettre "fait main" puis avoir des photos d'usine
- ❌ Mélanger Maroc / Tunisie / Algérie sous "Maghreb" dans les descriptions
- ❌ Réduction permanente "-20%" — dévalue l'artisanat. Préférer prix juste + transparence
